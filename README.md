Train Reservation System
Project Overview

The Train Reservation System is a console-based application developed in C++ that simulates the basic operations of a railway reservation system. The project allows users to manage trains, passengers, and ticket bookings efficiently using Data Structures and Object-Oriented Programming concepts.

The system supports:

Adding and managing trains
Passenger registration
Ticket booking and cancellation
Train searching by route
Viewing booking history
Generating system reports
Technologies & Tools Used
Programming Language: C++
Concepts Used:
Object-Oriented Programming (OOP)
Data Structures & Algorithms (DSA)
Binary Search Tree (BST)
Linked List
Dynamic Memory Allocation
Libraries Used:
iostream
string
Development Environment: Any C++ Compiler (Dev C++, Visual Studio, CodeBlocks, VS Code)
Data Structures Used
1. Binary Search Tree (BST)

Used to store and manage train records efficiently based on Train ID.

2. Linked List

Used to manage booking records dynamically.

3. Arrays

Used for storing passenger information.

Main Features
Train Management
Add new trains
Store train details such as route, timing, seats, and fare
Display all trains
Passenger Management
Add passenger information
Generate unique passenger IDs
Ticket Booking
Book tickets for available trains
Automatic seat allocation
Booking confirmation with unique booking ID
Ticket Cancellation
Cancel existing bookings
Restore seat availability after cancellation
Train Search
Search trains using source and destination
Booking History
View all bookings of a passenger
Report Generation
Display total number of trains, passengers, and bookings
Validation Features
Prevent duplicate train names
Prevent same source and destination
Ensure seats and fare are greater than zero
Validate booking and passenger IDs
